# Old address redirect

This repository only exists so that the old link
https://boetav.github.io/EPWP_Registration/ keeps working. Every page here
(including links such as `capture.html` or `#apply`) sends the visitor to the
same page at https://boetav.github.io/ecdoh-epwp-registration/.

`404.html` is a copy of `index.html`; GitHub Pages serves it for any address
that does not exist here, which is how deeper links are forwarded.

The real site lives in https://github.com/BoetaV/ecdoh-epwp-registration.
